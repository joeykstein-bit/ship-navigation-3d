# Ship Navigation (3D)

A 3D Unity remake of [Ship Navigation: Uncharted Waters](https://github.com/joeykstein-bit/ship-navigation). Steer between islands, whirlpools, fog banks and wildlife.

**Play:** https://joeykstein-bit.github.io/ship-navigation-3d/

Controls: ← → or A / D to steer, Space to set sail, C to switch between the chart and deck views.
